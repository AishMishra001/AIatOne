# AI at One 

It is an software application at keeps up updates about all the upcoming AI announcements , trends , new jobs , ...everything at one place . 


features : 

1. AI generated Articals (Daily updates) in 4 different catogories :
    -  Latest AI annoucements and updates
    -  Latest AI jobs updates
    -  Latest AI trends updates
    -  Latest AI tools updates
2. AI chatbots (4 chatbots) to get the updates in the catagories:
    - For latest annoucements and updates 
    - For latest jobs updates
    - For latest trends updates
    - For latest tools updates
    
3. Real time AI Updates
    - Live announcements and updates from different AI companies
    - Live jobs updates
    - Live trends updates
    - Live tools updates
  


## Tech Stack : 


### Frontend : 

Reactjs + ( ts / js ) + tailwind + daisy ui


### Backend : 

Bun + ( ts / js )

Rag pipeline + Free Models from OpenRouter 

Redis
